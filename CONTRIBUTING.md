# Contributing

Target Windows x64 with Python 3.12 and Node.js 22. Follow the source setup in the README, then run `python -m pytest` and `node --test tests/*.test.cjs` in PowerShell. Qt tests run in isolated child processes; real CUDA checks require compatible hardware.

Include a reproducible problem, a focused change, and relevant test results in pull requests. Keep automation identifiers and project schema compatible, and update both interface languages when adding UI copy.

Do not commit user projects, city datasets, model meshes, local endpoints, tokens, simulation results, or screenshots containing private models. Reproduce problems with small synthetic inputs generated by tests. Windows binaries belong in GitHub Releases, not Git history.
